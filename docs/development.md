# Guía de Desarrollo de Cyc-AI

## Principios

- Una responsabilidad por clase.
- API sin lógica de negocio.
- Los servicios coordinan procesos.
- El Coach nunca calcula fisiología.
- Physiology nunca genera recomendaciones.

## Convenciones

- Clases en PascalCase.
- Métodos en snake_case.
- Dataclasses para modelos de dominio.
- Comentarios solo cuando aporten contexto.

## Flujo de trabajo

1. Diseñar.
2. Implementar.
3. Probar.
4. Actualizar documentación.
5. Commit.
6. Push.
